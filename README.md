# 🔍 اسکریپت نمایش اطلاعات و امنیت سیستم لینوکس (System Info)

این یک اسکریپت خط فرمان (Bash) قدرتمند است که اطلاعات سیستم شما را در **۴ سطح مختلف** نمایش می‌دهد. از اطلاعات سخت‌افزاری پایه گرفته تا بررسی عمیق نقض‌های امنیتی و تهدیدات بزرگ، همه در یک ابزار جمع‌آوری شده است.

---

## ✨ ویژگی‌ها

- **نمایش اطلاعات پایه**: هسته، پردازنده، حافظه، دیسک و کاربران آنلاین.
- **اطلاعات شبکه**: آی‌پی داخلی/خارجی، دروازه، پورت‌های باز و مک‌آدرس.
- **بررسی امنیتی سطح متوسط**: لاگ‌های ورود ناموفق، خطاهای Sudo، سرویس‌های خراب و پردازه‌های مشکوک.
- **بررسی امنیتی سطح پیشرفته (بحرانی)**: فایل‌های SUID، کرون‌جاب‌های خطرناک، تنظیمات SSH، کاربران ریشه‌ای غیرمجاز و رمزهای خالی.
- **خروجی رنگی و زیبا**: برای تشخیص سریع خطرات (قرمز = بحرانی، زرد = هشدار، سبز = سالم).
- **سازگاری بالا**: روی اکثر توزیع‌های لینوکس (Ubuntu، Debian، CentOS، Fedora و ...) کار می‌کند.

---

## 📋 پیش‌نیازها (Prerequisites)

- یک سیستم عامل **لینوکس** (هر توزیعی).
- دسترسی به **ترمینال** (خط فرمان).
- برای سطوح ۳ و ۴، نیاز به دسترسی **ریشه (root/sudo)** دارید تا لاگ‌های سیستمی و فایل‌های امنیتی را کامل بخوانید.
- نصب بودن ابزارهای زیر (اکثراً به صورت پیش‌فرض نصب هستند):
  - `bash`
  - `awk`, `grep`, `sed`, `find`
  - `ip`, `ss` (برای شبکه)
  - `systemctl` (برای بررسی سرویس‌ها)
  - `curl` یا `wget` (برای دریافت آی‌پی عمومی - اختیاری)

> 💡 در صورت عدم وجود برخی ابزارها، اسکریپت به روش جایگزین متوسل می‌شود یا آن بخش را نادیده می‌گیرد.
